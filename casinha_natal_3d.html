Casinhas De Natal 3D

Como fazer seu pedido
1
Toque nas fotos dos modelos que você quer. Ao tocar, a foto fica verdinha com ✔. Pode escolher quantos quiser! (Tocou sem querer? É só tocar de novo para desmarcar.)
2
Quando terminar de escolher todos, toque no botão verde "Enviar pedido no WhatsApp" lá embaixo.
3
O WhatsApp vai abrir com uma mensagem de texto já pronta, com o nome dos modelos que você marcou. É só apertar enviar!
📷 Atenção: as fotos NÃO são enviadas!
As fotos estão aqui só para você ver e escolher o modelo. O que chega para o Leandro é apenas o texto com o nome dos modelos que você marcou, e é com ele que ele encontra o seu pedido rapidinho.
Para escolher vários modelos de uma vez, abra este arquivo no Chrome ou no Safari. Se não conseguir, toque em "Pedir este pelo WhatsApp" embaixo do modelo que você quer.
